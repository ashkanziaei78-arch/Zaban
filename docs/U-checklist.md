# U. چک‌لیست راه‌اندازی — کارهایی که باید انجام دهید

> نسخهٔ تعاملی این چک‌لیست با تیک‌های ماندگار جداگانه منتشر شده.
> هر دو از `docs/build-checklist.py` ساخته می‌شوند، پس هیچ‌وقت با هم اختلاف پیدا نمی‌کنند.

**۳۰ کار، در ترتیبی که هر کدام به قبلی وابسته است.**
۶ گام «دروازه»اند: تا انجام نشوند هیچ گام بعدی معنی ندارد.

کل کار حدود دو تا سه ساعت است، ولی سه جا باید منتظر بمانید — انتشار نیم‌سرور
(تا ۲۴ ساعت)، تأیید قالب پیامک (چند روز)، و نماد اعتماد (چند هفته).

**سامانه از پایان مرحلهٔ سه واقعاً قابل استفاده است.** مرحله‌های چهار به بعد
لازم‌اند ولی جلوی کار را نمی‌گیرند: تا وقتی پیامک راه بیفتد، کد ورود را از
پنل سوپرادمین می‌خوانید و به کاربر می‌گویید.

  - ⚠ **توجه**: ‏.htaccess فایل مخفی است. اگر نمی‌بینیدش، در File Manager از منوی Settings گزینهٔ «Show hidden files» را روشن کنید — آپلود شده، فقط دیده نمی‌شود.

- [ ] **۵ گواهی SSL رایگان بگیرید** — ۵ دقیقه

## مرحلهٔ دو — پنل
*۷ کار · ۴۰ دقیقه*

- [ ] **۸ زیردامنهٔ panel را بسازید** — ۳ دقیقه
  - Websites & Domains ← Add Subdomain
  - `panel`
  - دامنهٔ والد: talkora.ir — مسیر پیش‌فرض پلسک را دست نزنید.

- [ ] **۹ نسخهٔ PHP و افزونه‌ها را تنظیم کنید** — ۵ دقیقه
  - روی زیردامنهٔ panel.talkora.ir ← PHP Settings ← نسخهٔ ۸.۱ یا بالاتر
  - مطمئن شوید pdo_mysql و curl و mbstring روشن‌اند.
  - ⚠ **توجه**: اگر curl خاموش باشد همه‌چیز درست به نظر می‌رسد ولی هیچ پیامکی فرستاده نمی‌شود. نصب‌کننده در همان صفحهٔ اول این را به شما می‌گوید.

- [ ] **۱۰ یک پایگاه دادهٔ خالی بسازید** — ۵ دقیقه
  - Databases ← Add Database — یک کاربر هم برایش بسازید و رمزش را نگه دارید.
  - ⚠ **توجه**: پلسک معمولاً به نام دیتابیس و نام کاربر پیشوند اضافه می‌کند. همان چیزی را یادداشت کنید که در فهرست Databases می‌بینید، نه چیزی که تایپ کردید. این رایج‌ترین دلیل «اتصال برقرار نشد» است.
  - جدول‌ها را نسازید؛ نصب‌کننده خودش می‌سازد.

- [ ] **۱۱ بستهٔ talkora-panel.zip را در httpdocs زیردامنه آپلود کنید** — ۵ دقیقه
  - باید این‌ها را ببینید: index.html، پوشه‌های api و setup و fonts. (پنل سوپرادمین اینجا نیست — بستهٔ جداگانهٔ خودش را دارد، در مرحلهٔ سه.)
  - ⚠ **توجه**: پوشهٔ _نصب-آپلود-نکنید را آپلود نکنید. فقط نسخهٔ پشتیبان دستی است.

- [ ] **۱۲ گواهی SSL زیردامنهٔ پنل را بگیرید** — ۵ دقیقه  ← **دروازه**
  - SSL/TLS Certificates ← panel.talkora.ir
  - ⚠ **توجه**: کوکی ورود پرچم Secure دارد. روی http کاربر بلافاصله بعد از ورود بیرون می‌افتد و هیچ پیام خطایی هم نمی‌بیند. این را قبل از نصب انجام دهید.

- [ ] **۱۳ صفحهٔ نصب را باز کنید و سه فرم را پر کنید** — ۱۰ دقیقه  ← **دروازه**
  - `https://panel.talkora.ir/setup/`
  - صفحهٔ اول خودش سرور را بررسی می‌کند. صفحهٔ دوم چهار مقدار دیتابیس گام قبل را می‌خواهد و دکمهٔ «آزمایش اتصال» پیش از نصب می‌گوید درست است یا نه. صفحهٔ سوم نام کاربری و رمز پنل سوپرادمین را می‌سازد.
  - نصب‌کننده خودش جدول‌ها را می‌سازد، کلید امضای کدهای ورود را تصادفی تولید می‌کند، و فایل پیکربندی را — اگر بتواند — بیرون از پوشهٔ وب می‌نویسد.
  - ⚠ **توجه**: رمز پنل سوپرادمین بازیابی خودکار ندارد. همان‌جا جایی امن ذخیره‌اش کنید.
  - ✓ چطور مطمئن شوم؟ پیام «نصب تمام شد» و شمارش جدول‌های ساخته‌شده.

- [ ] **۱۴ پوشهٔ setup را پاک کنید و دو آزمون امنیتی بدهید** — ۵ دقیقه
  - در File Manager پوشهٔ setup را حذف کنید.
  - `https://panel.talkora.ir/api/config.php`
  - باید ۴۰۴ یا ۴۰۳ یا صفحهٔ خالی بدهد. اگر محتوای فایل را دیدید، فوراً رمز دیتابیس را عوض کنید.
  - `https://panel.talkora.ir/setup/`
  - باید ۴۰۴ بدهد (چون پاکش کردید) یا بگوید «از قبل نصب شده».

## مرحلهٔ سه — اولین ورود
*۳ کار · ۱۵ دقیقه*

- [ ] **۱۵ بستهٔ سوپرادمین را آپلود و وارد شوید** — ۱۰ دقیقه
  - پنل سوپرادمین زیردامنهٔ جداگانه‌ای است، نه زیرپوشهٔ پنل. یک بار زیردامنهٔ admin را در پلسک بسازید (Add Subdomain، دامنهٔ والد talkora.ir)، بستهٔ talkora-admin.zip را در httpdocs همان زیردامنه استخراج کنید، config.sample.php را به config.php تغییر نام دهید و چهار مقدار دیتابیس را دقیقاً مثل پنل وارد کنید — جزئیات کامل در docs/V-super-admin.md و راهنمای-سوپرادمین.txt داخل همان بسته.
  - `https://admin.talkora.ir/`
  - با همان نام کاربری و رمزی که در نصب پنل ساختید — جدول admin_user مشترک است، پس اینجا فرم ورود می‌بینید نه فرم ساخت حساب.

- [ ] **۱۶ سربرگ «سلامت سامانه» را باز کنید** — ۵ دقیقه
  - هرچه سبز نبود، توضیح و راه درست‌کردنش کنار خودش نوشته شده.
  - ✓ چطور مطمئن شوم؟ همه سبز، جز «پیامک» که تا مرحلهٔ شش زرد می‌ماند و عمدی است.

- [ ] **۱۷ با شمارهٔ خودتان وارد پنل آموزشگاه شوید** — ۵ دقیقه  ← **دروازه**
  - `https://panel.talkora.ir/`
  - شماره و نام و نام آموزشگاه را بزنید. کد ورود پیامک نمی‌شود — در پنل سوپرادمین، سربرگ «ورود و پیامک» ظاهر می‌شود. همان را وارد کنید.
  - اولین کسی که با نام آموزشگاه ثبت‌نام کند، نقش «مدیر» می‌گیرد.
  - ✓ چطور مطمئن شوم؟ پیشخوان آموزشگاه بالا می‌آید و نام آموزشگاه‌تان را می‌بینید. از این لحظه سامانه واقعاً قابل استفاده است.

## مرحلهٔ پنج — ایمیل با دامنهٔ خودتان
*۴ کار · ۳۰ دقیقه کار، تا ۲۴ ساعت انتظار*

- [ ] **۲۱ سرویس ایمیل دامنه را روشن کنید**
  - Mail ← Mail Settings ← talkora.ir ← Activate mail service

- [ ] **۲۲ صندوق‌های info@ و admin@ را بسازید** — ۵ دقیقه

  - `admin@talkora.ir`

- [ ] **۲۳ رکوردهای SPF و DKIM و DMARC را بگذارید** — ۱۰ دقیقه  ← **دروازه**

  - ⚠ **توجه**: بدون این سه رکورد، ایمیل‌های شما در پوشهٔ اسپم می‌افتند — از جمله اعلان درخواست دموی مشتری‌ها.

## مرحلهٔ شش — پیامک
*۳ کار · ۳۰ دقیقه کار، چند روز انتظار تأیید*

- [ ] **۲۵ در sms.ir ثبت‌نام کنید و اعتبار بخرید** — ۱۵ دقیقه
  - احراز هویت و خرید اعتبار اولیه.

- [ ] **۲۶ قالب «ارسال وریفای» بسازید** — ۱۰ دقیقه
  - پنل sms.ir ← ارسال وریفای ← افزودن قالب، دقیقاً با این متن:
  - `کد ورود شما به تاکورا: #CODE#`
  - ⚠ **توجه**: حتماً «وریفای» و نه ارسال معمولی. پیامک وریفای از خط خدماتی می‌رود، پس به کسی که «لغو تبلیغات» را فعال کرده هم می‌رسد. با خط تبلیغاتی، کد ورودِ بخشی از کاربران هرگز نمی‌رسد و شما هم خبردار نمی‌شوید.
  - تأیید قالب معمولاً چند روز طول می‌کشد. در این مدت سامانه کار می‌کند و کد ورود را از پنل سوپرادمین می‌گیرید.

- [ ] **۲۷ کلید و شناسهٔ قالب را در پنل سوپرادمین بگذارید** — ۵ دقیقه  ← **دروازه**
  - پنل سوپرادمین ← ورود و پیامک. کلید API، شناسهٔ عددی قالب، و نام پارامتر (CODE). بعد حالت را روی «با پیامک از sms.ir» بگذارید و ذخیره کنید.
  - به هیچ فایلی دست نمی‌زنید.
  - ✓ چطور مطمئن شوم؟ از یک شمارهٔ دیگر وارد شوید؛ پیامک باید برسد. اگر نرسید، حالت را به «کد در پنل» برگردانید تا کسی پشت در نماند.

## چیزهایی که هنوز نمی‌توانید انجام دهید

این‌ها عمداً ساخته نشده‌اند، نه اینکه جا مانده باشند:

- **پرداخت آنلاین شهریه** — نیازمند نماد اعتماد و قرارداد با یک درگاه است. کد پول باید فقط-افزودنی و قابل حسابرسی نوشته شود؛ عجله در آن گران‌ترین اشتباه ممکن است.
- **حضور و غیاب خودکار و ضبط کلاس** — به یک سرور اختصاصی BigBlueButton نیاز دارد، نه هاست اشتراکی.
- **ایمیل با صف و تلاش دوباره** — الان از mail() خود PHP استفاده می‌شود. برای اعلان «یک نفر دمو خواست» کافی است و شکستش هم ثبت می‌شود، ولی اگر روزی رسید پرداخت ایمیل شد، باید به SMTP با صف تبدیل شود.
